# GratefulHerber

A Grateful Dead inspired herbalism and alchemy addon project for WoW Classic Era.

## Concept preview

![Grateful Herber addon concept](docs/images/grateful-herber-concept.png)

This is an illustrated visual concept, not an in-game screenshot or a claim that the artwork is implemented. It shows herb inventory and session loot counts, planned Alchemy crafts, and a combined reagent shopping list. Gathering and crafting remain under the player's control.
